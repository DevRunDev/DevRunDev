# 1. Django App 설계
| **App 명** | **설명** | **다루는 Model** |
|------------|---------|----------------|
| **accounts** | 사용자 및 강사 신청 관리 | `User`, `InstructorApplication` |
| **courses** | 강의 및 강의 콘텐츠 관리 | `Course`, `Section`, `Lesson` |
| **enrollments** | 수강 신청 및 학습 진행 관리 | `Enrollment`, `LessonProgress`, `Certificate`, `CartItem` |
| **quizzes** | 퀴즈 관리 | `Quiz`, `Question`, `Choice`, `QuizAttempt`, `Answer` |
| **reviews** | 강의 리뷰 관리 | `Review` |

# 2. URL 설계
- **사용자 관리 (`accounts`)**
  - `/accounts/login/` → 로그인
  - `/accounts/logout/` → 로그아웃
  - `/accounts/profile/` → 프로필 조회
  - `/accounts/instructor/apply/` → 강사 신청

- **강의 관리 (`courses`)**
  - `/` → 강의 목록 조회
  - `/courses/{id}/` → 강의 상세 조회
  - `/courses/lessons/{id}/` → 레슨 상세 조회
  - `/courses/create/step1/` → 강의 생성 (1단계)
  - `/courses/create/step2/` → 강의 생성 (2단계)
  - `/courses/create/step3/` → 강의 생성 (3단계)
  - `/courses/create/step4/` → 강의 생성 (4단계)
  - `/courses/review/` → 강의 심사 페이지
  - `/courses/instructor/dashboard/` → 강사 대시보드
  - `/courses/{id}/edit/` → 강의 수정
  - `/courses/sections/{id}/add/` → 섹션 추가
  - `/courses/sections/{id}/edit/` → 섹션 수정
  - `/courses/sections/{id}/delete/` → 섹션 삭제
  - `/courses/lessons/{id}/add/` → 레슨 추가
  - `/courses/lessons/{id}/edit/` → 레슨 수정
  - `/courses/lessons/{id}/delete/` → 레슨 삭제

- **수강 관리 (`enrollments`)**
  - `/enrollments/enroll/{course_id}/` → 강의 수강 신청
  - `/enrollments/enroll/{course_id}/success/` → 수강 신청 성공 페이지
  - `/enrollments/lesson/{lesson_id}/complete/` → 레슨 완료 처리
  - `/enrollments/dashboard/` → 학생 대시보드
  - `/enrollments/` → 전체 수강 목록 조회
  - `/enrollments/{id}/` → 개별 수강 상세 조회
  - `/enrollments/{id}/generate-certificate/` → 수료증 생성
  - `/enrollments/certificate/{id}/` → 수료증 조회
  - `/enrollments/certificate/{id}/download/` → 수료증 다운로드
  - `/enrollments/cart/` → 장바구니 조회
  - `/enrollments/cart/add/{course_id}/` → 장바구니 추가
  - `/enrollments/cart/enroll/` → 장바구니에서 수강 신청
  - `/enrollments/cart/remove/{course_id}/` → 장바구니에서 제거

- **퀴즈 관리 (`quizzes`)**
  - `/quizzes/course/{course_id}/quizzes/` → 퀴즈 목록
  - `/quizzes/course/{course_id}/quizzes/create/` → 퀴즈 생성
  - `/quizzes/{id}/` → 퀴즈 상세
  - `/quizzes/{id}/edit/` → 퀴즈 수정
  - `/quizzes/{id}/delete/` → 퀴즈 삭제
  - `/quizzes/quizzes/{quiz_id}/questions/create/` → 문제 생성
  - `/quizzes/questions/{id}/edit/` → 문제 수정
  - `/quizzes/questions/{id}/delete/` → 문제 삭제
  - `/quizzes/quizzes/{id}/take/` → 퀴즈 응시
  - `/quizzes/attempts/{id}/result/` → 퀴즈 결과 조회

- **강의 리뷰 (`reviews`)**
  - `/reviews/course/{course_id}/add/` → 리뷰 작성
  - `/reviews/review/{review_id}/edit/` → 리뷰 수정
  - `/reviews/review/{review_id}/delete/` → 리뷰 삭제
